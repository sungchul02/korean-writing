# korean-writing

한국어 글(학술 논문, 국문 요약, 보고서, README 등)을 쓰거나 고칠 때 쓰는 Claude Code 스킬이다. 문장 규칙, 끝맺음과 수치 표기, 쓰지 않는 표현, 서술 순서, 용어 일관성, 단락·장 나눔, 기준 원고에 맞추는 방법을 담았다.

## 설치

`SKILL.md`를 `~/.claude/skills/korean-writing/SKILL.md`에 둔다. 국문 원고·보고서 작성, 원고 수정, 문체 다듬기를 요청하면 Claude Code가 이 스킬을 불러 쓴다.

---

A Claude Code skill for writing and revising Korean text (academic papers, reports, READMEs): sentence rules, endings and number formatting, phrases to avoid, section order, terminology consistency, and paragraph structure. Install by placing `SKILL.md` at `~/.claude/skills/korean-writing/SKILL.md`.
